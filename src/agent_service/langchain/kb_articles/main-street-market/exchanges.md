# Exchanges

If something doesn't fit or isn't quite what you expected, you can exchange it for a different size or color of the same product within 30 days of delivery. Exchanges are free: we send you a prepaid label, and the replacement ships at no extra cost.

## How to request an exchange

1. Go to **Order history** and select the order.
2. Choose **Exchange items** instead of **Return items**.
3. Select the new size or color. Only options that are currently in stock are shown.
4. Send the original item back using the prepaid label within 7 days.

To get you the replacement faster, we ship it as soon as the carrier scans your return package — you don't have to wait for the original to arrive back at our warehouse. You'll get an email with tracking details for the replacement once it ships.

## If the size or color you want is out of stock

If the option you want isn't available, you can join the waitlist for that option or return the item for a refund instead. We can't hold stock for exchanges, so if the option sells out between your request and our shipping it, we'll refund you and email you to let you know.

## Price differences

Exchanges for a different size or color of the same product are always at the same price, even if the product's price has changed since you ordered. You won't be charged more or refunded the difference.

## Exchanging for a different product

The exchange option only covers a different size or color of the same product. If you want a completely different product, we treat it as two separate transactions: a return of the original item, which follows our standard returns policy, and a new order for the item you want. This means the return shipping fee applies unless you're a Plus member, and you'll be charged for the new order right away, with the refund for the original arriving after we inspect it.

## Exchanges on gifts

If you received the item as a gift, you can exchange it using the order number on the gift receipt. The replacement ships to you, not the original buyer, and the buyer isn't notified about the exchange.

## Final sale items

Final sale items can't be exchanged, even for a different size. Check the product page before ordering if you're unsure about sizing — most clothing pages include a size guide with measurements.
