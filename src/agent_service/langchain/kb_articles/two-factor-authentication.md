# Two-factor authentication

Two-factor authentication (2FA) adds a second step when you sign in: after entering your password, you also enter a 6-digit code from an authenticator app or a text message. Even if someone learns your password, they can't sign in without the code.

## Turning on 2FA

1. Go to **Account settings**, then **Security**.
2. Select **Turn on two-factor authentication**.
3. Choose an authenticator app (recommended) or text message.
4. For an authenticator app, scan the QR code with the app and enter the 6-digit code it shows. For text messages, enter your mobile number and the code we send you.
5. Save your backup codes somewhere safe.

We recommend an authenticator app over text messages, because text messages can be intercepted or delayed, and don't work without mobile signal.

## Backup codes

When you turn on 2FA, we give you 10 backup codes. Each code can be used once, instead of a 6-digit code, if you don't have your phone. Store them somewhere safe and separate from your phone, such as a password manager or a printed copy at home. You can generate a new set of codes at any time from the **Security** page, which cancels the old ones.

## Remembering trusted devices

When you sign in with 2FA, you can tick **Trust this device for 30 days**. We won't ask for a code on that device again for 30 days, unless you change your password or sign out of all devices.

## Turning off 2FA

You can turn off 2FA from the **Security** page. You'll need to enter your password and a current 6-digit code or backup code. We don't recommend turning it off.

## Lost phone and no backup codes

If you've lost access to your authenticator app or phone number and don't have any backup codes, you won't be able to sign in on your own. Contact support to start account recovery. For your security, recovery is deliberately slow: we verify your identity using the last four digits of a card used on a recent order and a recent order number, then wait 3 business days before removing 2FA from the account. During those 3 days we email the address on the account, so the real owner can cancel the request if it wasn't them. We can't speed this process up.

## Changing phones

If you're moving to a new phone, sign in on the new phone first and set up 2FA there using **Replace authenticator** on the Security page, before you wipe or trade in the old one.
